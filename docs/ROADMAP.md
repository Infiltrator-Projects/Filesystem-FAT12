# FAT12 roadmap

The installed filesystem product is one Common V2 shared object and its manual. The hosted and freestanding profiles share the format engine; generic consumers negotiate their actual operation masks. Separate per-format Linux, EFI or FUSE drivers are not milestones for the production product.

## Qualification and remaining work

- Preserve exact-revision portable amd64 DEB and source-downloading native RUN qualification, including native CPU optimisation and installed package ownership.
- Extend real-media namespace and corruption tests across supported geometry, naming, metadata and capacity limits.
- Qualify every optional Common V2 defragmentation map, plan, execute, verify and recovery capability independently. Retained dedicated historical code is not evidence of a public V2 operation.
- Demonstrate allocation integrity and data preservation under interrupted mutation and explicit recovery.
- Independently qualify the freestanding reader in the actual BOOT consumer and the generic kernel integration; a compiled module or host fixture is insufficient.

See [README](../README.md), [validation](VALIDATION.md) and [current qualification workflows](https://github.com/Infiltrator-Projects/Filesystem-FAT12/actions?query=branch%3Amain). No milestone is certified by this roadmap alone.
